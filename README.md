## Demo data

Install the bundle and initialize the database, then run `bin/rails db:seed` to
create 100 demo clients, 50 carriers with three reviews each, and 200 marketplace
listings. The seed also creates the Israeli locations and product catalog those
records need. It can be rerun safely; demo records use `example.test` email
addresses and are not intended for login.
